چیکاچوب ایرانیان — بسته شروع نسخه موبایل

محتویات:
- index.html: نمونه فعلی فروشگاه
- manifest.webmanifest: مشخصات نصب به‌صورت وب‌اپ روی اندروید
- sw.js: پوسته آفلاین اولیه

مهم:
این بسته هنوز اپلیکیشن نهایی یا فروشگاه متصل به سرور نیست. سفارش‌ها، درخواست همکاری و تغییرات محصولات در نسخه فعلی نمایشی/محلی هستند و نباید برای سفارش واقعی استفاده شوند.
برای نصب‌پذیری PWA، فایل‌ها باید روی یک دامنه با HTTPS میزبانی شوند و تگ manifest و ثبت service worker در index.html اضافه شود. برای فروشگاه واقعی، API سمت سرور، پایگاه داده، ورود امن مدیر و ذخیره‌سازی امن تصاویر باید جداگانه ساخته و آزمایش شوند.
